
# Trabajo Práctico de Programación - Hoja de Vida

Este repositorio contiene la entrega del proyecto en HTML y CSS que representa una hoja de vida interactiva y páginas secundarias de navegación.

## Estructura de archivos:
- `index.html`: Página principal con la información general de la hoja de vida.
- `estilos.css`: Hoja de estilos compartida para dar formato visual al sitio.
- `pagina1.html`: Sección de proyectos desarrollados.
- `pagina2.html`: Sección de contacto.
- `README.md`: Descripción general del repositorio.
