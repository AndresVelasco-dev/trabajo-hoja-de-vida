Aquí presento algunos de los proyectos y aplicaciones en los que he estado trabajando, aplicando lógica de programación, bases de datos y herramientas modernas de desarrollo.

🏢 Sistema de Reservas para Salones Comunitarios

Tecnologías: PHP, XAMPP, phpMyAdmin, HTML5, CSS3

Aplicación web diseñada para la gestión de reservas en salones de zonas residenciales. Incluye validaciones lógicas de fechas (restringiendo reservas entre 48 horas y 90 días de anticipación) y conexión directa con base de datos relacional.

💻 Recomendador y Tienda de Componentes PC

Tecnologías: HTML, CSS, JavaScript / Lógica web

Plataforma interactiva orientada al armado de computadores personalizados según el presupuesto del usuario, enfocada en la compatibilidad de hardware (fuentes de poder, tarjetas gráficas y procesadores).

🎮 Prácticas de Lógica y Videojuegos

Tecnologías: Python, Java, C#

Ejercicios avanzados de algoritmos y pequeños prototipos enfocados en mecánicas interactivas y estructuras de control, integrando el desarrollo de videojuegos como motor de aprendizaje continuo.
